## 소개 · About

I'm a C++ developer from Korea, living in Otaru, Hokkaido. I spend my time in game internals: how Unity games load assets, and where they break. Reverse engineering and modding are how I learn most of it.

```yaml
focus:     game internals, C++ tooling, modding
location:  Otaru, Hokkaido, Japan (UTC+9)
languages: Korean (native), Japanese (business), English (working)
```

## What I work on

- Game internals: how Unity-based games structure their runtime systems, from update loops to asset loading.
- Tooling: small C++ programs built to answer one specific question about how a program behaves.
- Modding: extending existing games and documenting what I find in the process.
