## `field notes`

<sub>Things I keep in mind while tracing a target.</sub>

```text
[offsets]   an RVA belongs to a build. signatures can help locate code, but still need validation.
[structs]   a layout is a hypothesis until offsets, alignment, lifetime, and runtime behavior agree.
[unreal]    generated SDKs are build-specific. confirm important layouts against the target binary.
[unity]     validate metadata, binary, and tool versions together; a successful dump can still be wrong.
[dxgi]      swap-chain hooks must account for resize, resource recreation, and lifecycle changes.
[network]   length + opcode + payload is one possible layout, not a universal protocol format.
[authority] a client can request a state change; the server should validate authoritative state.
[tracing]   compare successful and unsuccessful runs to narrow down the responsible code path.
[kernel]    test drivers in an isolated VM with a kernel debugger attached.
[method]    record the build, the observation, the inference, and what remains unknown.
```
